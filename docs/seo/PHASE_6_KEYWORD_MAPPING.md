## 1. Research Methodology & Sources

### Research Sources Used
1. **Repository & Experience Ground Truth Inspection:** Inspected `src/data/personal.js`, `src/data/experience.js`, `src/data/skills.js`, `src/data/services.js`, `src/data/projects.js`, `src/data/seo.js`, `src/data/socialLinks.js`, and all UI sections to anchor every keyword strictly to verified skills and built software.
2. **Search Engine SERP & Ecosystem Grounding (`search_web`):** Investigated regional hiring and portfolio demand in Kerala (Malappuram corridors including Perinthalmanna, Manjeri, Kottakkal, Tirur; plus Kozhikode Cyberpark, Kochi Infopark, and Thiruvananthapuram Technopark) across React.js, Python/Django, ASP.NET Core MVC, ERP, and AI/Gemini integrations.
3. **Brand Footprint Check:** Verified existing search visibility of `akhileshp.com` in search results for branded developer queries (`Akhilesh P`, `akhileshp.com`) covering React.js, ASP.NET Core MVC, ERP modules, and Ebsor Infosystem experience.
4. **Search Console / Autocomplete Structural Alignment:** Aligned page titles, headings, and topic clusters to informational, commercial/hiring, and navigational intent patterns observed on developer portfolios in Kerala.

### Data Limitations (Verified vs. Unverified Metrics)
- **No fabricated numerical metrics:** Automated access to private Google Search Console query impression exports, Google Keyword Planner exact monthly search volumes, Google Trends index time series, or paid third-party KD scores (Ahrefs/Semrush) was not available in this workspace environment.
- Accordingly, **Search Volume** and **Competition** fields distinguish explicitly between **Observed Qualitative SERP Demand** (from web research and regional job portals such as Infopark/Technopark/Indeed/Naukri) vs. **Unavailable Quantitative Volume** (pending user lookup in Google Keyword Planner / GSC Performance report after indexing).

## 4. Cannibalization Guardrails Applied

1. **`ecommerce` vs. `aishka`:** `/projects/ecommerce` targets functional cart/checkout/API e-commerce engineering (`E-commerce Web Application — React.js Storefront`), whereas `/projects/aishka` targets fashion/apparel visual collection browsing (`Aishka Clothing Website — React Fashion Storefront`).
2. **`code7-erp` vs. `pos-business-management` vs. `kidonex-feedback`:** `code7-erp` focuses on shipped enterprise Kendo UI + ASP.NET Core ERP modules; `pos-business-management` focuses on retail POS 12-module functional architecture and accounting workflow design; `kidonex-feedback` focuses specifically on customer review capture via ASP.NET Core MVC controllers and REST validation.
3. **`taskflow` vs. `inkspace` vs. `daybook`:** `taskflow` owns Python Django task management + reminders + Groq/Gemini planning; `inkspace` owns Django blogging/editorial publishing + CKEditor + Gemini writing assist; `daybook` owns React Native mobile daily reflection & Planning Grade.
4. **Homepage `/` vs. `/projects/*`:** The homepage targets broad persona, location (`Malappuram, Kerala`), and multi-stack hiring/freelance queries while passing contextual equity via descriptive anchor text into each dedicated case study URL.
